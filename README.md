# Seventimenews Job Generator — starter

## Included
- `index.html`: responsive UI, manual job details, two required information lines, live preview, HTML copy and download.
- AI extraction, rewriting, and image generation are intentionally not connected yet. Those require a secure backend and API credentials.

## Next setup
1. Create a new GitHub repository named `seventimenews-job-generator`.
2. Upload `index.html` to the repository root.
3. Connect the repository to Cloudflare Pages.
4. Deploy with no build command and output directory `/`.
5. Then configure a Cloudflare Worker and API secrets for URL extraction, AI writing, and image generation. Never put API keys in `index.html`.
